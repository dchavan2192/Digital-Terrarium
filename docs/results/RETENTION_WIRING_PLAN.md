# Can mutation supply functional memory wiring?

Freeze 32 matched founder seeds 6200–6231. Each population has 16 fresh native Genome::random controllers with one cue input, two hidden nodes and seven outputs. All begin feed-forward. Use the same balanced five-blank stationary task as the previous pilot. Raw turn sign decides correctness (zero predicts positive). Rank by correct count, minimum signed turn, then lowest ID. For 24 replacements retain four adults and produce 12 children sampled uniformly from them. Use native reproduce with weight mutation probability 0.1, step 0.2, all other structural and trait mutations off except the specified recurrence-add rate. Disable independent diet mutation.

Run three arms per seed: fitness-ranked survivors with recurrence-add 0.3, uniformly sampled survivors with recurrence-add 0.3, and fitness-ranked survivors with recurrence-add zero. All arms clone identical founders. Use a separate RNG for neutral survival. The arms share seed labels but native mutation can consume different draws. Archive every distinct genotype on birth, training readouts, lineage, all ranked generation memberships and all final winners. Lock the best final training-ranked member per arm before diagnostics.

The primary outcome is the fraction of final champions meeting all of these conditions at five blanks: both hidden cues correct, minimum signed hidden response at least 0.1, hidden probe responses identical after boundary reset, both visible cues correct after the same reset, and at least one expressed recurrent connection. The signed-margin threshold is an engineering choice to exclude tiny sign differences. Also report sign-only outcomes separately, keeping the other criteria. Record paired wins/ties/losses against both controls. Repeat the diagnostics at 4/5/6 and 19/20/21 blanks to expose duration and parity effects. Include every seed, failure and zero. This is selection in a stationary task with a supplied mutation operator and fixed founder layout.
