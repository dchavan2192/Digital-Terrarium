# Fixed and variable training delays

Use 32 fresh matched founder populations (6300–6331), the wiring discovery study's native genome layout, mutation settings and 24-generation search. Both arms use fitness selection and begin feed-forward. Each candidate receives both cues at four delays. Fixed training repeats five blanks four times. Variable training uses 3, 4, 6 and 7 blanks. Both schedules total 20 blanks and eight presentations. Each trial starts with zero neural state. Rank by total correct, then minimum signed margin across all eight responses, then ascending ID.

Lock each population's best final training-ranked member before evaluating unseen delays 8, 9, 18 and 19. Primary endpoint is the number of matched populations whose champion passes all four, reporting variable-only, fixed-only, both and neither. At each delay apply the earlier criterion: an expressed recurrent connection, both hidden answers correct with minimum signed margin 0.1, identical hidden answers after reset, and both visible answers correct after reset. Retain all histories, failures, probes and per-delay counts. These scheduled delays carry no explicit timing input. Fresh seeds support the paired comparison; this experiment alone cannot establish ecological fitness.
