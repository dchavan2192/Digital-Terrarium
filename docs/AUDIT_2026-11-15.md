# Implementation and roadmap audit — 2026-11-15

Scope: static review of the core tick loop, genomes, activity metrics, configuration, experiment runner/launcher/analysis, and WASM frontend. `cargo check --workspace --offline` passed. No simulation, remote experiment, deployment, or browser QA was performed. Findings below distinguish code behavior from unmeasured consequences.

## Findings that block interpretation of new experiments

### 1. Amplified sharing remains an energy source

`sim.rs`, sharing block: donor loses `share_amount`, recipient receives `share_amount * benefit_multiplier`, capped at maximum reserves. Defaults are 5 and 1.5. Below the reserve ceiling, each transfer creates 2.5 energy; two reciprocating creatures each net 2.5 before other costs. There is no separate sharing overhead beyond the transferred amount. Crowding/metabolic costs can offset this, but do not enforce conservation. Whether stationary groups currently sustain themselves is unmeasured.

Decide explicitly whether this is food transfer or an abstract group subsidy. For food transfer, require received energy <= donor expenditure. If benefits represent warmth/defense, model the corresponding avoided cost, or charge a resource for additional yield. Log transferred, dissipated, and externally supplied energy separately. Add a controlled no-food reciprocal-sharing regression before ecological tuning. Do not require movement merely to suppress clustering: clustering can be valid behavior; resource-free net energy is the issue.

### 2. Combat can operate on nonpositive reserves

`sim.rs`, metabolism -> construction -> combat -> sharing -> reproduction -> death order: energy can become nonpositive while `alive` and the previously calculated `action.alive` remain true. Combat uses `scaled_damage.min(target.energy)` without a lower clamp. For example, prey at -2 yields damage -2 and negative attacker gain. Creatures reduced to zero by combat also remain eligible targets and may execute their queued attack before death resolution. Sharing can rescue zero-energy recipients later that tick.

Define the intended death/rescue boundary. Clamp extractable prey energy to nonnegative values, prevent unintended postmortem actions, and add regression cases for depleted attackers, depleted victims, multiple attackers, and rescue ordering. These are code-path findings, not measured population-level effects.

### 3. Cap-limited reproduction confounds the ecological baseline

`sim.rs`, reproduction: births are skipped when current living count plus offspring reaches `hard_cap`. Deaths are resolved afterward, so organisms already at nonpositive energy still occupy cap slots. Parents are processed in persistent vector order; scarce birth slots can favor earlier entries. Lowering the cap does not establish food limitation.

Phase 9a is correctly prioritized, but must follow the sharing/death audit. Track cap-binding ticks, number of eligible births rejected, energy sources/sinks, population distribution, and extinction. Choose the food-limited config using pilot seeds, then validate on separate seeds. Require that the cap rarely binds across the experimental arms, not just the all-ON control. Account for the newly enabled fruit resource.

### 4. Sweep configurations bypass validation after mutation

`sweep.rs` validates the base TOML through `Config::from_file`, then changes fields using `apply_param` and calls `run_with_config` without revalidation. `Config::validate` also omits several relevant bounds: finite values, nonnegative costs, transfer efficiency bounds, total brain node capacity, and reproductive energy balance.

Expose reusable validation and validate each generated job before execution. Reject impossible brain sizes and invalid probabilities/costs; explicitly specify whether child energy may exceed parental expenditure. Currently the defaults conserve energy at asexual birth and dissipate energy at sexual birth, but arbitrary configurations need not.

## Roadmap corrections

### Crossover item G needs a more precise description

Inheriting fitter-parent disjoint/excess edges is the explicitly implemented policy, so inheriting that edge set before mutation is not by itself evidence of a bug. `crossover` also calls `reproduce`, so final offspring can undergo structural mutations. The substantive unresolved problem is historical identity: hidden IDs are allocated within each genome, allowing independently created, different nodes to appear homologous. Test cross-lineage node identity, inherited depths, feed-forward validity, and matching-gene semantics before claiming robust topology recombination. Fix this before recurrence complicates it.

### Phase 7 status mixes implementation with validation

Label mechanics as implemented / correctness-checked / experimentally validated separately. Raw cumulative activity is not a demonstration of unbounded adaptation. A neutral shadow is useful, but a positive finite-run difference should be reported as evidence under that null model, not proof of unboundedness. The representation already has finite bounds (`MAX_NODES = 64`, `MAX_CONNECTIONS = 512`), so indefinite structural-complexity growth is unavailable without changing those bounds. ActivityTracker retains all observed hashes; profile archive memory for long runs.

### Experiment tooling does not implement the proposed factorial design

`launch_pi_phase7.sh` launches four arms: all-ON, sex OFF, niche OFF, epigenetics OFF, with five seeds each. Reusing an identical all-ON control is reasonable, but this is not the proposed sex × niche × epigenetics × drought factorial (16 combinations). The runner accepts one sweep parameter at a time. Start with targeted ablations; add explicit multi-factor manifests only when testing interactions.

The launcher's inner sequential shell lacks fail-fast behavior, so an earlier failed sweep can be followed by a final `DONE` marker. Add per-job completion/error status. Persist commit/source hash, full config, seed, build/platform, metric/hash version, requested and completed ticks, and completion status in a unique run directory. Current filenames can overwrite repeated runs.

The analysis uses the simulation RNG for environmental events, so the same seed does not guarantee the same drought schedule after feature switches alter RNG consumption. Use independently seeded environment streams or replay explicit drought schedules for controlled drought-response comparisons. Treat each run as the independent experimental unit. The existing analysis already aggregates by seed and corrects multiple comparisons; retain that. Recovery times that hit the observation limit are censored, not observed recoveries. Global population recovery also does not directly establish offspring-specific epigenetic benefits.

### Phase 9 should put evaluation before learning

Recommended sequence: genome/checkpoint export -> behavioral arenas and controls -> recurrence -> recurrence ablation -> plasticity -> plasticity ablation. Delayed foraging needs controlled cues and state resets; detour tests require actual barriers, which the current world lacks. Evaluate unseen environments and compare with memory disabled/reset. Keep inherited weights, lifetime plastic weights, and methylation distinct. Include an epigenetic control that retains stress response but resets inherited marks, to separate lifetime response from transgenerational inheritance.

### Phase 8 is useful, with bounded scope

Finish explainability and correctness before more visual polish. The frontend already exposes a mock-data badge; preserve it and verify real WASM loading during browser QA. Check that displayed actions distinguish inferred cues from actual executed actions. Genome export and energy-flow telemetry support both the viewer and research, so prioritize those shared dependencies.

## Recommended execution order and gates

1. Energy accounting, sharing policy, death/combat semantics, sweep validation; controlled regression tests.
2. Phase 9a food-limited baseline; Pi pilot and independent validation seeds; negligible cap binding and explicit extinction reporting.
3. Genome homology/crossover correctness, snapshots, run provenance, independent environmental randomness.
4. Targeted Phase 7 ablations with prespecified endpoints. Add the neutral shadow if activity is an endpoint; no requirement to finish OEE work before unrelated ecological experiments.
5. Behavioral evaluation, then recurrence, then plasticity, each separately compared.
6. Expand to factorial interactions and long-duration activity studies only after pilot effect sizes and compute costs are known. Defer HGT, multicellularity, primordial chemistry, and speculative performance refactors.
