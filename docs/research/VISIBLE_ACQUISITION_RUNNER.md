# Visible acquisition runner — implementation handoff

`sim-runner acquire-visible --protocol configs/visible_acquisition.toml --arena configs/delayed_choice.toml --output output/visible-acquisition`

Separate serial genetic optimization; no ecological simulation. This implements council gate 1 only. Example protocol: 64 random founders, 25 replacement generations plus generation zero, seeds 2000/2001/2002, 8 elites, tournament size 3 with replacement, declared 20-input/8-hidden/7-output layout. Native weight mutation 0.1/0.2; topology, recurrence and scalar-trait mutation disabled. Native neutral hue drift remains, unused by the arena. No reference solutions are injected. All methylation starts zero and stays fixed. Morphology does not affect movement.

Fitness is the number of correct first contacts across the two balanced visible cue trials, with wrong/timeout zero. No distance shaping, delayed-task score, or held-out feedback enters training. Persistent lower candidate ID breaks score ties; final champion is the best final population member by that same rule. This coarse fitness may plateau; preserve failure rather than change the rule retrospectively. No early stopping. Report founder success separately from improvement so lucky founders are not called acquired behavior.

Unique sessions retain exact resolved protocol/arena, embedded founder defaults, build provenance, manufactured controls, all founders and final genomes, all generation scores/parents, final innovations and champion training traces. Independent unit is the founder-population seed. Champion traces repeat training conditions; there is **no held-out validation**. Technical failed runs are recorded and remaining seeds attempted; overall command then returns failure. An interrupted process leaves `manifest.json` status `started` without a completed root summary—do not call it completed.

Validated bounds before artifacts: population 2–256, replacements 1–1000, at most 16 unique seeds/1,024 archived population entries, valid slots/probabilities, recurrence/topology/trait mutation off, at most 2M neural steps/1B conservative edge steps including controls/champion replay, and 100k total retained trace samples. Shared arena engine has a trace-free path to avoid per-generation trajectory allocation. Tests compare scoring/terminal behavior with detailed controls and independently replay seeded CLI runs.

This is implementation plus engineering smoke validation, not a completed acquisition study. Before an actual pilot, pin clean source, protocol, arena and binary; save hashes and a runtime estimate, then run the fixed seed list on the Pi. Do not run a long local campaign. After inspecting that feasibility pilot, freeze fresh validation before evaluating generalization. See [council](SCIENCE_COUNCIL_2026-11-17.md). The separate overnight structural-growth diagnostic does not waive this gate.
